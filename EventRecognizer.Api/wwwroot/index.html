Limpieza del mes

Envía los eventos del mes mostrado en el calendario (más los eventos sin fecha) al LLM para detectar duplicados: el mismo evento anunciado en varios posts. El LLM decide cuáles son el mismo evento comparando cuenta, fecha/recurrencia, resumen y caption — no solo el título. Se eliminan las copias conservando un evento por grupo, y si un evento sin fecha ya está en el calendario, se elimina el que no tiene fecha. Requiere tu API key de DeepSeek.
